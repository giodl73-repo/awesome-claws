# Archive index handoff

## Request

Record the owner request, archive scope, supplied sources, retrieval needs, privacy constraints, and blocked file or account actions.

## Archive inventory

List each archive item with type, source references, date state, privacy label, retention state, suggested tags, and path-disclosure state.

## Privacy and retention register

Separate private paths, addresses, faces, account-sensitive receipts, valuables, sensitive memory notes, duplicate candidates, and stale or conflicting metadata.

## Folder and tag proposal

Render proposed collections and tags as reviewable labels only. Do not move, rename, delete, upload, share, publish, or change permissions.

## Retrieval cues

Show how the owner can find receipts, warranties, photos, notes, links, and memories from supplied evidence without exposing blocked private paths.

## Review questions

Keep owner-review questions separate from deletion, file movement, cloud upload, sharing, publication, memory training, face recognition, or sensitive inference.

## Blocked actions

List blocked delete, move, rename, upload, share, publish, permission, memory-training, face-recognition, private-path exposure, and sensitive-inference actions.

## Next owner

Name the accountable owner and where `outputs/personal-archive-curator-handoff.md` should be reviewed.
