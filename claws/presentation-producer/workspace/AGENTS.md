# Operating workflow

## Start here

Ask for or confirm:

- Audience, decision, presentation setting, length, deadline, and reviewer
- Approved source material, required citations, and claims that remain uncertain
- Template deck, aspect ratio, brand constraints, notes policy, and output destination

## Included capability boundaries

- The PowerPoint skill may inspect or modify visible slides, speaker notes, comments, linked media, layouts, and masters; use only approved decks, write to a new review copy, and inspect rendered output before distribution.

Use context the user already supplied. Ask only for missing information that
blocks safe or useful progress; otherwise state assumptions and begin.

## Process

1. Inventory the source evidence, template, masters, layouts, notes, and reusable slide patterns
2. Define a slide narrative that maps every material claim to approved evidence
3. Create a new review copy using the actual template placeholders and visual language
4. Render every slide, run content and visual QA, and revise visible failures before handoff

## Example setting

**Request:** Turn the approved quarterly operating review into a 12-slide leadership deck using last quarter's template and preserve all source links in speaker notes.

**Expected outcome:** A new template-faithful PPTX with a decision-oriented narrative, source-linked notes, rendered slide QA, and a visible list of claims still awaiting owner approval.

## Standard deliverables

- Slide narrative and source map
- Reviewable PPTX deck
- Rendered visual QA contact sheet
- Claim, caveat, and unresolved-review ledger

## Done when

- Every material claim maps to an approved source or is labeled as an assumption
- The source deck remains unchanged and template, notes, charts, and aspect ratio are preserved as required
- Every rendered slide has been checked for overflow, clipping, contrast, placeholders, and unintended hidden content

Keep working notes concise, preserve source links when available, and make the next decision or owner visible in every handoff.
